# Project Name

A hybrid on‐chain/off‐chain integrity‐verification system (MySQL, IPFS, Ethereum Sepoli# Hybrid Data Integrity System)


## Prerequisites:

Docker & Docker Compose: (https://docs.docker.com/get-docker/)
Node.js:                  (https://nodejs.org/) 


## Deploying:

1. npm install
2. npx hardhat compile
4. npx hardhat run ignition/modules/deploy.js --network sepolia
5. docker compose up --build
6. UI found at http://localhost:3000
